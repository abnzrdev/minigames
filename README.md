# MiniGames

A responsive **game-discovery app** built for the [RS School Qualifying Stage](https://github.com/rolling-scopes-school/qualifying-stage/tree/main/tasks/minigames). Browse and filter games, view leaderboards and game details, sign in with Firebase, and interact through favorites and comments.

**[Live demo](https://abnzrdev.github.io/minigames/)** · **[Application code (`story-4`)](https://github.com/abnzrdev/minigames/tree/story-4)** · **[Review & test evidence](https://github.com/abnzrdev/minigames/pull/46)**
