# MiniGames

A responsive game-discovery web app built for the [RS School Qualifying Stage](https://github.com/rolling-scopes-school/qualifying-stage/tree/main/tasks/minigames).

**[Live demo](https://abnzrdev.github.io/minigames/)** · **[Source (`story-4`)](https://github.com/abnzrdev/minigames/tree/story-4)** · **[Review PR](https://github.com/abnzrdev/minigames/pull/46)**

**Features:** Game catalog, filters, leaderboard, authentication, favorites, and comments.

**Stack:** TypeScript, Vite, Sass, Firebase, REST APIs, Vitest.

*RS School coursework. The implementation is on `story-4`; `main` contains this overview.*
